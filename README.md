# Sport Client

Leanback sports fixture tracker and media player client for Android TV, Fire TV, and Android mobile devices.

### Features
- D-pad remote navigation for Android TV & Firestick
- Live fixture schedules and match score tracking
- Adaptive video playback engine
- 100% ad-free
